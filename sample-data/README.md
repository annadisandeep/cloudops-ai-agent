# Sample Data

Everything here is **synthetic**, generated by the application's demo mode.

- `sample-incident-report.md` — a real Markdown export of a completed demo investigation (HTTP 5xx scenario), exactly as produced by `GET /api/v1/investigations/{id}/report.md`.
- `demo-scenarios.json` — the six demo incident scenarios as served by `GET /api/v1/scenarios`.

The demo telemetry itself (metrics, logs) is generated deterministically at request time by `backend/app/demo/data.py` — there are no static fixture dumps to keep in sync.

# CloudOps AI Agent

An AI-powered cloud operations platform that investigates infrastructure incidents with evidence — not guesses. A bounded LangGraph agent pulls monitoring metrics, logs, and resource metadata through read-only tools (GCP, AWS, or a fully simulated demo environment) and produces structured, evidence-cited incident reports behind a minimal monochrome React dashboard.

> The full implementation (backend, frontend, agent, tests, Docker, CI, Terraform, and documentation) is being introduced via pull request from [`feature/cloudops-ai-agent-mvp`](../../tree/feature/cloudops-ai-agent-mvp).
